# Genuine v4 unused-head NPU proposer

Exact source archive of the reviewed live factory and Root-bound comparison
adapter. The small proposer uses the already-qualified unused-head bridge;
weights, the native GPU consumer and scalar recurrent operations are unchanged.
The explicit `--enable-unused-head-append` flag enables the path on the actor
thread before seeding each fresh context. Default invocation leaves it off.
Provider path/hash proof, restored-instruction counts and actual context cleanup
are retained in the genuine v4 terminal report. Unknown counts remain undefined.

The [source manifest](source-manifest.json) records exact private materialization
paths and hashes; the adapter belongs one directory above the live producer.
These scripts need the existing frozen lifecycle/RAW bindings and private model
assets. No model, SDK, compiled DLL or credential is included. CPU factory/adapter
tests use fake backends; they do not establish live speed or acceptance.

The planned experiment keeps the same 32K capacity, paired8192 settings, exact
8192-token request, 128 output tokens and unchanged memory policy. It requires
stock/NPU/stock arms, each with one excluded warmup plus three measured requests,
exact target IDs/output and normal server restoration. Earlier incomplete series
remain intact. Component time cannot be converted into engine token rates.
