# Native Attention BT4 OPT0 experiment

These are historical source snapshots of the completed Halogen 0.17.2 stock/candidate/stock comparison. They are not runnable helpers in this archive location: their path calculations require the original private directory layout, runtime preparation, profiles and sealed receipts.

The sole environment delta was `HALOGEN_ATTN_QS_BT4_OPT=0`. Each window used one excluded warmup and three measurements on the same 8,192-token synthetic pseudoprose prompt and 128-token non-copying generated output. No qualified gain was established. The candidate remains disabled and must not be repeated unchanged. No model or device payload is bundled.

Results, timing limits and independent review: `docs/benchmarks/halogen0172-native-attn-bt4-opt-20261008.md` and JSON.
