# Native I4R fallback experiment

These are historical source snapshots of the completed stock/candidate/stock
cohort, not runnable helpers in this archive location. They require the original
private directory layout, runtime preparation, profiles, dependencies and exact
receipts. Their relative path calculations refer to that original layout.
Do not rerun the rejected candidate without a different mechanism.
The launcher changes only native HALOGEN_I4R_LAST=0, is default-off and sealed
with an independently supplied SHA256. No model or device object is bundled.
See docs/benchmarks/halogen0172-native-i4r-fallback-20261008.md and JSON.
