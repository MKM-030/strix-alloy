# Retained K3 controller source and CPU substrate

This private folder implements a durable slot quarantine and optional copied K3 ready provider. It includes a freestanding C++ controller, host CPU fixtures, five Linux x86-64 relay templates, an errno-preserving ENDBR64 callback and an explicit default-off cold installer. No installer invocation, native patch, lifecycle change, API request or accelerator initialization is performed.

`python -B build_qualify.py` executes ordinary host CPU fixtures, builds the Linux objects/shared library offline, checks relay exits/relocations/FDEs, and matches native seam bytes against the pinned current ELF. It writes only inside this directory. The host assembly smoke executes Stock/Scalar/Ready, optional admission loss, preparation and both pending flag gates against fake native continuations. Its Windows instruction bytes match the linked Linux template bytes except the two FS-to-GS TLS prefixes; it verifies all GPRs, flags including DF, red zone, errno and full configured XSAVE image preservation. The Linux TLS/unwind runtime and cold installer are not executed here.

The same build also checks the installer's exact SHA routines against three independent known CPU byte fixtures covering empty, short and multi-block data. `qualification_receipt.json` records command exits, source/binary hashes and the linked copied five-FDE envelope; `delivery_seal.json` freezes the header/library/receipt hashes and remaining root integration requirements. LLD's synthetic `.eh_frame` handling is avoided by renaming the relay object's frame section before linking the private island. The linked FDEs, CIE encoding and exact final terminator are checked after this rename.

Each mapped-image admission clears the previous image base before inspecting the current instructions. A CPU fixture admits an image, emulates each late rejection (`CpuRejected`, `IslandRejected`, and `MapFailed`), changes the mapped reset/Ready/Scalar instruction, and verifies that a retry rejects the changed image without retaining the old base.

The mandatory relay gate uses retained `Lane` model/slot/phase independently of collector state, readiness, callback enable, TLS/stack admission, XSAVE or producer loss. An active retained slot reseeds Request cooldown to `INT_MAX`, disables native MTP generation and cached opening, and defaults Entry to authoritative native Scalar. A disabled/unavailable/stale/busy provider therefore retains Scalar. The lane and relay memory/code must remain installed until completed full native reset or process exit even after optional provider close.

| Entry 0 | `0x173fcd5` | Stock replays CMP, resumes the existing native JLE at `0x173fcdc`; Ready `0x173fd86`; Scalar `0x1740408` |
| Prepare 1 | `0x1782bdc` | Preserve native reset accounting, force saved DL=1, replay model load, resume `0x1782be3` |
| PostReset 2 | `0x173ce9a` | Complete only actual null-cache/fresh-native reset, replay aggregate load, resume `0x173ce9f` |
| InitialFlag 3 | `0x173cc71` | Suppress MTP after native SETE, replay holder load, resume `0x173cc78` |
| ChunkFlag 4 | `0x1746c96` | Suppress MTP after native SETE, replay chunk LEA, resume `0x1746c9d` |

Entry owns `Lane.round` exactly once per retained native transaction before optional dispatch. One nonblocking CAS assigns it; contention/overflow disables readiness and preserves quarantine. Ready lookup uses the already assigned round and never advances it. Frame and Invocation belong to the current relay invocation. The optional callback can promote only Scalar to Ready after exact owner, native record, pins, history/current/position, capacity, ordinary-ID and final loss/native snapshot checks. It copies all three IDs including the opener and sets saved R13=3. Native target verify, accepted recurrent-state commit, output/history and stop/EOS handling stay native.

The five templates preserve GPRs, ordinary PUSHFQ flags and the complete native red zone. Entry callback saves/restores the complete admitted standard XSAVE mask. Action at image-base-16 and XSAVE pointer at image-base-8 are invocation-owned and outside the XSAVE region. Each exit chooses its action before full restoration and continues through direct rel32. The callback uses a real balanced indirect CALL/normal RET and restores errno. The templates carry their existing native caller unwind rules: outer CFA `0x1a40`, preparation CFA `0x30`, chunk CFA `0x120`. A startup installer must link/fix and register the copied `.eh_frame` in the same relative island layout before publishing any native entry.

Pending materialization survives normal holder destruction before Request birth. Transfer requires the same holder/model/slot/wire/cache generation/ticket and a fresh-reset marker in the same retained generation. PostReset preserves a newly armed Pending generation and records that marker. For old Request/Quarantined generations it releases the quarantine only when aggregate+8 is null, the retained slot is current, native position/bookkeeping are zero, and cached opening/carry positions are invalid. This relies on the bounded one-slot Cache Off native prefill path: beginning that new prefill excludes a still-running old transaction even if an optional retirement observation was lost. It does not restore an old MTP snapshot or establish safe multi-slot cache restore.

`retained_controller_source.so` includes `hgn_dflash_install_cold(const cold::Arguments*)`. Null/default-off arguments return Off without any work. Explicit enable=1 verifies one startup thread, full current `/proc/self/exe` SHA/size/stability, mapped executable segment/seam bytes, complete admitted standard XSAVE mask and callback ENDBR64, copies a linked code/FDE island near native text, fixes all exit rel32 fields, checks/registers all five FDEs, then publishes all five pinned entry jumps while cold. There is no constructor or environment arming. Failures after publication preparation begins exit the process instead of continuing partial gates. The containing DSO, Lane and provider configuration are retained through process exit.

Root integration must establish the isolated one-slot Cache Off scope, supply the retained Lane/provider context, invoke cold installation before native execution or threads, and register each native thread's actual mapped stack bounds via `hgn_dflash_register_current_stack`. The installer does not interpose pthread creation; missing bounds disable readiness and preserve Scalar. Mandatory capture requires at least 280 bytes of unconditional stack headroom. Optional admission additionally covers XSAVE/alignment and the caller's complete callback/provider/signal budget (at least 81920 bytes). `hgn_dflash_disable_optional` plus `hgn_dflash_optional_drained` close the optional provider only; no API removes the mandatory gate or Lane during quarantine.

The ready callback accepts only an already-computed copied result and never dispatches or waits. A causal provider scheduling window after committed features/output and before the next Entry is still required for serving integration. This source/CPU qualification proves neither that window nor serving correctness, drafter acceptance, generalization or performance. The exact native source proof remains in the read-only sibling `dflash-controller-bridge-20261009`.
