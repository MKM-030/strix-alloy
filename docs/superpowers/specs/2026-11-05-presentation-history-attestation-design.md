## Architecture and choices

Use a separately bounded caller-authenticated attestation operation on the existing own Global `/updates` resource after a validated CREATE and cleanup ownership. Keep the existing CREATE request/reply unchanged. A bounded private Bridge task uses one explicitly delegated bootstrap credential use; startup never awaits this task. Attestation failure disables optional history and never changes or retries CREATE. Existing Guest producer then uses the private per-session nonce plus provider authentication to append only bounded untrusted presentation metadata.

Callback pull was considered. The configured connection uses basic_auth_credentials; the documented RESTMessageV2 Basic profile expects sys_auth_profile_basic. A direct reference substitution is unsupported, and pull adds connection/action/routing and worker qualification. It remains an alternative if the selected path cannot be qualified.

## Credential and task lifetime

Before the existing credential is taken/cleared, an enabled session may delegate exactly one separately owned purpose-bound attestation sublease with the SAME original <=45second deadline. Its immutable purpose is the pair (exact fixed HTTPS ServiceNow origin plus `/api/global/scc_voice_context/updates`, exact operation `attest_presentation_history_v1`); neither plain URL nor another operation qualifies, and no purpose fragment enters the transport URL. Creating this sublease is explicit; it cannot be created or resurrected after clear/expiry, transferred across sessions, used for another URL/operation or taken twice. Normal primary credential consumption does not recreate the sublease. Whole-session failure/end/cancel revokes an unused lease; a legitimately handed-off task owns its own cleanup.

Only after validated_created -> observe_conversation_binding -> owned_cleanup_identity -> alive/ticket gate may the private task consume that sublease. It does not reuse caller_authorization_task or delay consume/queue_start_created. The request uses a new DummyCookieJar session, same fixed ServiceNow origin, original caller Bearer plus provider token, verified TLS/no proxy/no redirects/no retry, <=2seconds clipped to the original remaining deadline. Clear all private references on every terminal path. A remote grant after a timed-out response remains unused: optional history requires an exact positive receipt and the local raw nonce is erased on failure/end.

## Integration rulings after design review

The authenticated HTTP response is exactly {result: <the exact ten-field receipt>}; raw receipts, extra/error/failure wrappers and nonfinite/duplicate-key JSON are refused. The transport accepts at most4096 response bytes without automatic decompression.

A confirmed immutable C and exact attested grant may publish while business bootstrap_stage is still early. Optional publication may await its already bounded private task inside the existing overall2second publication budget; it must not introduce a startup await, retry or extra authorization use. Terminal/disabled state invalidates late receipt acceptance.

Native include diagnostics are optional and false by default. When explicitly enabled for qualification they emit only bounded actual native gsUserID, valid C, fixed enter/included/omitted stage and count0..3 under one fixed prefix. No text, prompts, ASR, nonce/hash, alias, error/source or reasoning data; logger failure cannot affect any result. This measures actual worker identity/inclusion in the same fresh qualification call.
