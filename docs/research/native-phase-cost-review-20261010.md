## Candidate ranking and cheapest useful next step

1. **Explicit graph replay of one unchanged complete native GPU operation:** the most distinct candidate with no arithmetic rewrite, conditional on recovering the current operation's complete dynamic ABI. Prefer a target verifier/model unit with a bounded fixed row shape over a whole-request graph; preserve host accept/reject, cached opening, stop and native state updates outside it. The immediate cheap action is finite source closure of the actual 0.17.4 dispatcher reached through 0x18bee70 / 0x1814e00, identifying every launch, copy/completion dependency, dynamic scalar, pointer lifetime and mutable counter. Stop if that closure supplies no safe reusable GPU unit. A new profiling-only engine cohort is not recommended. Graph replay remains a hypothesis: neither a component saving nor an end-to-end gain is currently measured.

2. **Whole-operation native GPU compute redesign:** possible after a real current component budget and complete arithmetic/dependency source exist, but materially more expensive than replaying the stock operation. Scratch-free N=3 FL already regressed 13.31%; a renamed owner/tile variation is not a new justified screen.

3. **Existing MTP Q4 LUT scheduling result:** keep disabled. Its 0.17.2 component saving is 11.2878 microseconds per tested projection, order sensitive, partial asset coverage, and excludes engine cache/arena state. The published optimistic 112-head extrapolation is only 1.2642 ms per retained request, not a current saving. It does not justify serving attachment or another cohort.

4. **PLD64, selector/refit, NPU/DFlash, CPU ID reciprocal, BN64, scalar/wait removal and closed configuration screens:** no unchanged rerun. PLD64 completed with zero substitutions; CPU reciprocal saved only 0.11945 ms per full 8K window; bulk BN64 and scratch-free FL were negative; moving a completion wait leaves upstream work. Prior draft/verification agreement studies do not provide current native subcosts. A different causal ingress or full proposer would require separate utility and full-cost evidence, not a policy refit against this retained natural cohort.

No measured claim favors drafting, verification, copies or ordinary decode over the others. For the present evidence, the critical measurable unit is aggregate native Decode. The graph source investigation is the cheapest new mechanism assessment; there is no justified promised performance experiment to launch merely because a finer clock is missing.
