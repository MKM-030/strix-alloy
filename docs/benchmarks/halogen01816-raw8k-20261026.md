# Halogen 0.18.16: measured RAW timing for 8192 → 128 tokens

The three measured requests produced **1186.787676 tokens/s prefill** and **48.576010 tokens/s decode**, using directly captured Linux `CLOCK_MONOTONIC_RAW` phase intervals. Draft acceptance was **210/318 = 66.0377%**. This qualifies timing for this instrumented task; it does not demonstrate an acceleration.

| Measurement | Prefill tokens/s | Decode tokens/s |
|---|---:|---:|
| RAW arithmetic mean | 1186.787676 | 48.576010 |
| RAW endpoint-bound range of that mean | 1186.787442–1186.787910 | 48.575987–48.576034 |
| Native clock, same intervals | 1095.20 | 44.79 |

The endpoint bounds describe timestamp bracketing, not statistical confidence or run-to-run variation. Native and RAW clocks measure different elapsed values. These RAW rates are calculated from the new captures; older normal/native results are **not rescaled**. Observer overhead remains included.

Four journals validated with distinct request IDs 3–6, four endpoint records and one prefill pair each. Ordinal 0 is the excluded warmup; ordinals 1–3 supply the arithmetic means. Each exact request processed 8192 input tokens and returned 128 tokens. Request bytes, output hash, finish reason, token counts, drafted/accepted counts and all scoped counters matched the completed plain cohort across all four ordinals. The measured totals were 24,576 input tokens, 384 output tokens, 318 drafted and 210 accepted.

Decode uses the native **128-token numerator** over the captured begin/end interval. The generated counter advances **1 → 128**, an observed delta of **127**; those conventions are recorded separately. No PP1 peak is combined with this MTP128 result.

Whole HTTP time measured by Windows QPC averaged **10.278978 s** in this instrumented cohort, compared with **9.759160 s** in the prior normal cohort. That is a descriptive 5.33% longer elapsed time, not a causal effect of instrumentation or an engine-speed claim.

The run used v2, 32K context, one slot, TextOnly/ThinkingOff, cache Off with `no_store`, 8192 chunk/arena, adaptive drafting (gate 0.90, PLD 3,3), and decode prefetch Off. Image and engine/request/source hashes are pinned in the [verified aggregate](halogen01816-raw8k-20261026.json).

ADLX samples fully inside the measured whole HTTP windows were **1228–1866 MHz** (11 samples), **895–1835 MHz** (10), and **1353–1906 MHz** (9). These are whole-request samples, not separately aligned prefill/decode clocks. No package-power cause is established; the active firmware power profile remains unconfirmed.
