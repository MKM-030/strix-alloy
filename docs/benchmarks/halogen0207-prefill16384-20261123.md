# Halogen 0.20.7 paired 16K prefill settings on Windows/WSL2

Doubling the prefill chunk and arena from 8,192 to 16,384 tokens raised
the working allocation from **5.6 to 7.8 GiB**. At 16,384 actual input
tokens, the generated text changed and native-head acceptance fell from
**64.52% to 55.77%**. At 8,192 actual input tokens, the text and draft
counts matched and the complete request time fell between the two
controls. The serving profile uses the 8,192-token settings.

| ---: | --- | ---: | ---: | ---: | ---: |
| 8,192 | 8,192 / 8,192 before | 1,974.12 | 55.93 | 192/291 (65.98%) | 6.299 |
| 8,192 | 16,384 / 16,384 | 2,010.61 | 57.62 | 192/291 (65.98%) | 6.316 |

The 16K candidate's complete HTTP time was 0.49–1.08% shorter. Its
answer diverged after 102 shared UTF-8 bytes in every repetition. The
response and draft differences prevent a matched-output speed claim.
Windows QPC measured dispatch through EOF. Prefill and Decode are means
of the native API rates. The native phase sums exceeded the QPC HTTP
intervals in 6 of 24 requests.

## Workload and verification

The same Halogen 0.20.7 v2 checkpoint and r2 HT4 drafter ran one 32,768
position BF16 slot in automatic concurrency mode. Each arm used the
same non-repetitive novel prefixes, Cache Off with `no_store`,
Thinking Off, Vision Off, temperature 0, seed 1, and 128 output tokens.
Each input size and arm used one excluded warmup and three measured
requests. The Windows power scheme was REV:N Performance.

The profile and native container exposed only the paired
`HALOGEN_PREFILL_CHUNK` and `HALOGEN_MAX_TOK` changes. The startup log
reported the settings and working allocations in each arm. Both
controls logged an intermediate 8,192-token boundary for all four
16,384-token requests. The candidate logged all four completions
without intermediate boundaries. The minimum request-sampled physical
or commit reserve was **23.01 GiB**. The lifecycle restored the ordinary
server on port 8840. The Voice health check reported ASR and TTS ready.

Raw responses, dispatch and EOF timestamps, and launch receipts are
retained locally under
`server/.local/halogen-update-20261122/primary0207/prefill-chunk-prep-v1/prefill-chunk-run-v1`.
