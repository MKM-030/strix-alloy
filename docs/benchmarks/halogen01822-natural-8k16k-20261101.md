## Measured complete-request improvement

Windows selected `REV:N Performance`. The existing OEM WMI interface was used
once to select **Performance (1)**, with fresh getter confirmation. BIOS 3.10,
drivers, voltages and global WSL settings were not changed. This is the same
mode mapping established in the [earlier OEM comparison](halogen01816-oem-performance-20261026.md).

Both windows use the same running 0.18.22 engine, profile and frozen request
bytes. Each input has one excluded warmup followed by three measurements.
The table uses Windows QPC around the complete HTTP request, before response
persistence. It does not infer separate phase rates from whole-request time.

This sequential before/after comparison has no final Quiet control. It records

**These are API-reported observations, not independently verified phase
throughputs or new best-result claims.** In all eight Performance requests,
the reported prefill-plus-decode duration exceeds the independently measured
whole HTTP duration. For example, measured 8K request 1 reports 7.2446 seconds
of phases inside a 6.7011018-second HTTP request. The clock inconsistency must
be resolved with fresh direct phase capture; no scaling factor or overhead
subtraction was applied. The earlier [0.18.16 RAW measurements](halogen01816-natural-8k16k-20261026-evening.md)
remain historical results with their own clock evidence.

Acceptance is the sum of accepted native head proposals divided by proposed
tokens after warmup exclusion. Lookup and grammar each proposed zero tokens.
Acceptance has **not increased** in this update. The separate native warmups,
each individual response identity, counters, timings and QPC intervals are
retained in the [JSON report](halogen01822-natural-8k16k-20261101.json).

## Start with Windows PowerShell 5.1

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Start-Halogen-ServiceNow.ps1 -Profile CurrentText32K -ConsoleTrace
```

Run from the repository. `-PrintOnly` displays the resolved configuration
without starting an engine or writing a session. Stop an existing session
through normal controls before starting another. This launcher selects the
software profile; it does not switch the separate OEM mode. The historical
`MeasuredText32K` preset remains pinned to 0.18.16.

[Official changes](https://github.com/peonist-ai/halogen-flash-server/blob/main/CHANGELOG.md)
principally improve concurrent Flash decoding in 0.18.20 and add separate
small NPU models in 0.18.21/22. Neither a matched two-request local throughput
gain nor Flash MTP offload to the NPU was measured here. The broader speed and
acceptance goal remains unachieved.
