# Halogen 0.20.7 sparse-attention union comparison

The sparse-attention union trial shortened Windows time from first visible text
through EOF by **6.19–6.56% at 8K** and **4.51–4.95% at 16K** against the
two stock windows. It also changed the generated bytes at both input sizes.
The deployment decision requires exact output parity. The normal serving
profile uses stock sparse attention.

Each window used the same frozen natural novel prefixes with 128 output
tokens, temperature 0, seed 1, Thinking Off, Vision Off, Cache Off and PLD
`3,3`. The v2 checkpoint and official r2-HT4 head ran in a single 32K
BF16 slot on the Windows REV:N Performance profile. The table excludes one
warmup per input length per window. Each mean represents three measured
requests, and the native acceptance column pools their draft counts.

The controller forwards `HALOGEN_ATTN_QS_UNION=1` only when explicitly set
in the managed 0.20.7 profile. The collector verified the environment in the
owned image. The pinned binary contains a branch to build a union of selected
four-token sparse-attention blocks for neighboring query rows, with a
per-row mask. Native dispatch and GPU kernel times were outside this run.
[Profiler capability check](../research/halogen0207-wsl-profiler-and-nested-clock-20261123.md)

Both stock windows reproduced the saved output hashes and head counts. Each
candidate window produced stable bytes across its four repetitions per input
length. Its output first diverged at byte offset 219 at 8K and 102 at 16K.
Native phase rates retain the API timing scope. Independent Windows QPC
measured first text and response EOF. At 8K full HTTP time fell
**2.66–3.36%** relative to the controls. At 16K it fell **0.56–0.83%**
and the first visible text arrived **28–46 ms later**.

The lowest sampled request reserve was 28.70 GiB. Raw streams, output bytes,
request timings, launch settings and native completion logs are retained
under `server/.local/halogen-update-20261122/primary0207/qs-union-campaign-prep-v1/qs-union-run-v1`.
The campaign restored the regular Halogen server on port 8840.
Authenticated model health and ServiceNow, Native Voice, TTS and ASR
readiness passed after restoration.
