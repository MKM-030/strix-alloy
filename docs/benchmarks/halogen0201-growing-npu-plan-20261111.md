It changes the old rebuilding strategy: seed the last 512 authoritative prompt IDs once, then grow through 640 IDs by appending the 128 recorded target output IDs. A count-one proposal reads owned logits and performs no speculative forward. No production server setting or driver is changed.

Each next-ID prediction is obtained before supplying that step's authoritative target ID to the NPU. A 16384-token native-ID teacher family is not present in this input pack; this experiment makes no second-family claim.
