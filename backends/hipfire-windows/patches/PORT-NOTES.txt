The eleven-file delta adds native buffered rank-table reads, worker-free loader
state, exact Windows x64 HIP R0600 identity/architecture ABI, Windows architecture
error propagation, host physical/commit and dedicated GPU budgeting, existing
focused CPU fixtures, capability docs, and root's Linux-only loaded-code resolver
repair. No model/kernel math, quantization, payload or driver change. Existing
SPDX/copyright headers are retained; bundled licenses/NOTICE are copied unchanged.
The source copy excludes Git metadata, target/dist and caches.

Dedicated budgeting requires exact nonzero HIP R0600 LUID matching exactly one
AMD DXGI adapter, node0, plus native PDH GPU Adapter Memory exact-LUID phys_0
Dedicated Usage with successful API calls, valid CStatus and nonnegative LARGE
value. It caps GPU free by HIP free/total, DedicatedVideoMemory-globalUsage and
LOCAL.Budget-LOCAL.CurrentUsage. The global counter already includes process
usage; it is not subtracted twice. SharedSystemMemory/NON_LOCAL never add credit.
PDH query handles close on every path. Missing identity/provider proof reports a
source diagnostic and falls back to the conservative host allowance.

Host allowance is min(availablePhysical.saturating_sub(18GiB),
availableCommit.saturating_sub(18GiB)),
using a validated same-process GlobalMemoryStatusEx snapshot. Zero allowance
admits zero GPU capacity even with dedicated proof. These snapshots are volatile;
root's continuous18GiB physical reserve guard and >=22GiB model-request guard stay
required. Existing model/KV/scratch reserves and allocation errors still apply.

Node mask1 identifies node0 normally. Root's typed HIP7.2/gfx1151 property query
reported mask0. The zero-mask exception is restricted to gfx1151, an actual
Integrated attribute and exactly one visible HIP device; exact AMD LUID+DXGI
node0+valid PDHphys0 remain mandatory. Root's real128MiB HIP allocation/memset/sync
charged that exact adapter's DXGI LOCAL node0 and global PDHphys0, qualifying this
narrow tuple. This does not establish other zero-mask/multi-node devices.

Root qualified exact R0600 ABI/architecture, typed HIP/DXGI identity and native PDH
accounting (results/dedicated-budget/pdh-result.jsonl). The final PDH source passed
a native release build, then one excluded warmup and three natural16K MTP2
